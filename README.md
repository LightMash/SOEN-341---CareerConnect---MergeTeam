# CareerConnect

## Project description
CareerConnect is a web application designed to help job seekers organize and manage their career search process in one place. The platform allows users to create accounts, sign in securely, track job applications, and keep their professional documents organized. The project aims to simplify the experience of applying for jobs by combining personal account management with practical tools for career growth.

## Setup instructions
1. Clone the repository.
2. Run the setup script (one-time, or after pulling changes to requirements.txt/package.json):
```bash
   cd "Sprint 1"
   ./setup.sh
```
3. Fill in `backend/.env` with the shared Supabase `DATABASE_URL` if setup.sh flagged it as missing.
4. Run both servers:
```bash
    cd "Sprint 1"
   ./run.sh
```
5. Visit the local URL shown by Vite in the terminal.
